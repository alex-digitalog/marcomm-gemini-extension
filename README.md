# Marcomm AI extension for Gemini CLI

Connects Gemini CLI to Marcomm AI (https://marcomm.works) over MCP with OAuth sign-in.

## Install

```
gemini extensions install https://github.com/alex-digitalog/marcomm-gemini-extension
```

The first tool call opens a browser window to sign in to Marcomm AI and pick a workspace. No API key is stored in this extension.

## Tools

Read: press releases, blog posts, press events, reports, journalists, media outlets, monitored companies, news coverage, pending approvals.
Write: press release drafts, blog post drafts, approval requests. Publishing and sending stay behind the approval flow in Marcomm AI.
